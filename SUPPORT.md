# Support and error reporting

For configuration help or an error in production, email [contact@opin-x.com](mailto:contact@opin-x.com?subject=AWS%20SMS%20plugin%20support).

The paid configuration consultation is described in the README. A GitHub account is not required to report an operational problem.

## Include this information

- Mautic version.
- AWS End User Messaging SMS plugin version.
- PHP version.
- AWS region.
- Whether the plugin is in `locked`, `canary`, or `production` mode.
- The exact steps that reproduce the problem.
- Expected result and actual result.
- Approximate UTC timestamp of the failed attempt.
- A short, sanitized log excerpt and the AWS error code, if available.

## Do not include

- AWS access keys, secret keys, session tokens, passwords, or cookies.
- Full ARNs, AWS account IDs, private URLs, or server connection details unless specifically requested through a secure channel.
- Recipient phone numbers, names, email addresses, contact exports, or message histories.
- Unredacted screenshots or full production logs.

For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
